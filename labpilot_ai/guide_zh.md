rc3 现场写入：在队列派发前导出任务，请独立操作者签发授权。请先阅读随包 RC3_OWNER_ZH.md。没有授权仍可只读检查。

首次使用
选择与本站受管 Runmanager、BLACS 共用的 profile。在「操作台」点「当前实验」，与 Runmanager 核对时序、输出目录和发数。「设备与能力」列出站点报告的通道与动作；「详细记录」显示原始回执。

跑一发
1. 在 Runmanager 选择时序，把所有扫描轴收为单值，使展开数恰好为 1。在 Lyse 勾选例程。在 LabPilot 确认分析方式为 native_h5。
2. 点「准备单发」。改参数或静态通道可使用「导入动作」加载已审 JSON，也可让智能体起草。静态测试前记录通道原值。
3. 选中草稿核对参数，再点「批准所选」，批准有效期 15 分钟。「执行队首已批任务」按队列顺序派发，选择某一行不会改变执行顺序。
4. 点「核对进度」。被选中的观察中任务每 15 秒更新一次；Lyse 尚未写出字段时继续等待。派发结果不确定时先查「事件记录」。测试结束按已审计划恢复原值。

接入智能体
在「设置 → 接入智能体」选 DeepSeek Harness，将 stdio 命令和参数复制到其 MCP 设置。选 Codex CLI 时，在 Anaconda Prompt 执行复制的注册命令。先让智能体查询时序、输出和发数，再起草任务，由操作者审批与执行。

桌面与语言
「设置 → 创建桌面快捷方式」会在当前 Windows 用户的实际桌面生成绑定当前 profile 的图标，并显示完整路径。语言在设置中即时切换，按 Windows 用户保存。

Suite 现场
点「读取 Runmanager」查看活动参数。点「获取 BLACS 设备」后选设备并读回状态。在操作台选中已有分析报告的任务，再打开报告目录。「新建动作」可从站点公布的动作中选择，填写实际参数后生成草案。
