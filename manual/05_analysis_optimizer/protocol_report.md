# Protocol Designer 与报告

Protocol 页面用于根据论文文字、PDF 摘要或图片描述生成实验设计建议。它和自然语言控制分开，默认不直接执行任何实验动作。

## Protocol Designer

输入可以是：

- 论文摘要。
- 实验方案文字。
- 图片描述。
- 人类输入的目标和约束。

输出应该是：

- 实验目的。
- 需要的时序。
- 需要扫描的参数。
- 建议的 lyse 字段。
- 风险和注意事项。
- 可转成自然语言控制命令的建议。

## 报告生成

multi 分析报告由 `analysis/report_generator.py` 生成 Markdown。内容包括：

- 数据来源。
- 选择的 H5 文件或文件夹。
- 使用的 lyse 模块。
- 图像路径。
- 拟合参数。
- 优化历史摘要。
- 简短结论。

## 原则

- Protocol 页面只生成建议。
- 用户确认后再复制或发送到 Command 页面解析。
- 报告必须引用可复现的数据字段和图像路径。
- 报错和警告可以附带 AI 修改建议，但不自动修改实验代码。
