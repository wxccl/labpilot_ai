# 0.3.2 — controller inspection fixes

Close the Harness MCP server using labpilot.exe before upgrading on Windows. In the controller's Anaconda Prompt:

    conda activate labscript
    python -m pip install --upgrade --no-deps labpilot-ai==0.3.2
    where labpilot
    notepad "%CONDA_PREFIX%\share\labpilot\controller_one_shot.md"

In your Harness MCP server editor add a stdio server: command = the **absolute labpilot.exe** reported above, arguments = three separate strings: `--profile`, the absolute path to your reviewed profile JSON, and `mcp`. Save, reopen settings, restart the client and verify that discovery and snapshot work. Remove the server in the same editor to roll back. Do not hand-edit generated cordis.patch.yml. The MCP server requires no provider key. An AI can prepare an action; an operator authorizes the exact task separately.

For the explicitly selected Paratera chat provider use `labpilot --profile PROFILE deepseek --provider paratera --model DeepSeek-V4.1-Flash-1017 "prompt"` with the appropriate provider credential and endpoint in the process environment. Keep credentials out of profiles and logs.
