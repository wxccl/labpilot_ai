# LabPilot 0.3.6rc2

The workflow window now opens in English, offers a persistent Chinese language option, and includes an operator guide, a Suite inspector, an action editor and task event history. Settings provides Codex CLI and DeepSeek Harness MCP registration details.

On the Windows controller, extract the release kit and run Setup-LabPilot-Desktop.cmd during an idle window. It installs the bundled wheel into the existing Suite environment and creates a shortcut on the current user's desktop. Use Settings > Create desktop shortcut to bind another selected profile.

Native H5 observation continues to rely on Lyse writing the configured result fields. A real controller shot is still required for site acceptance.
