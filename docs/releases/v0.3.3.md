## 两种入口

已有站点网关使用 labpilot-control，执行时仍须由网关核验请求及审批。打包的原生宿主使用 labpilot --profile，应用 A2/A3 任务授权。两个接口的计划、回执和审批不可互换。不要以脚本直接拼装请求来验证拒绝路径。

## 顺序和通过标准

1. **离线拒绝路径。** 在隔离环境验证错误操作员、过期快照、未暂停队列、回执无请求标识、摘要不符和 writer.lock 残留。预期：不会派发第二次；未绑定结果保留 UNKNOWN。锁和请求原件交现场管理员核对，不自动删除或归档。
2. **只读基线。** 记录站点版本、连接表摘要、设备/通道/子通道、单位、设备代次、队列状态、活动序列、输出目录、globals 原始表达式（含注释）及配置摘要。按标量和设备通道分别统计 DDS；不要把四通道和每通道三个寄存器计作同一种数量。
3. **静态小样本。** 在独占空闲窗口，由当班审批人选一条已确认可测的静态通道、允许范围和恢复值。先冻结队列暂停计划，核对 expected/desired 和回读；再写、重新取快照、恢复、逐项比对。暂停期间若出现新任务、在途设备或代次漂移，不自动解除暂停。Repeat 原为关闭时不要为了覆盖测试开启它。逐设备扩大前先验证小样本；DO 重写原值不证明翻转或外部执行器正常。
4. **参数往返。** 先在隔离 globals 副本测试带引号、中文、反斜杠和带行尾注释的扫描表达式。改变后用原任务的基线恢复；原始表达式、展开数与摘要都必须一致。并发编辑应导致拒绝。不要将字符串表达式作为普通字符串值提交。记录原 UNC 原文；无须手写 JSON 转义，使用序列化器。
5. **实机一发。** 使用已批准的现场序列和阈值，核实所有扫描轴已展开为恰好 1 发。用单独任务审批，只提交一次。编译、入队、BLACS 完成回调、H5 归属、Lyse 分析计数均为 1 且质量 PASS；证据不足只观察原任务。对已有 H5 做离线分析可以核验质量，但不能倒推出此前缺失的托管批次证据。
6. **复原。** 复核原 globals 字节意义上的表达式、输出路径、展开数、摘要、设备逐项读回、队列与 LabConfig。恢复 230 发配置不等于执行 230 发。现场保持日志和 H5，并记录无法独立测量的物理输出。

附件记载的是旧版结合站点工具的现场观察；不作为本版实机验收。没有为此次发布操作控制机或实验设备。
