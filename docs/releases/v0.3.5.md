# 0.3.5 — one operator context

Start with the [installation and acceptance guide](https://github.com/wxccl/labpilot_ai/blob/v0.3.5/manual/START_ZH.md). The release kit contains the official wheel, tagged source, Chinese guides and SHA256SUMS.txt.

- CLI, task UI and Harness expose the same active context. MCP can query capability preflight and task events.
- Managed batches can follow the selected local Runmanager output under an approved root, with a unique child directory per request.
- Independent Lyse routines can import reviewed station helper directories without a wrapper or global environment edit.
- Existing profiles and optional legacy tools remain available. The native Lyse GUI is not controlled by this analysis worker. Missing evidence, unconfigured physical thresholds and hardware faults still require operator review.
