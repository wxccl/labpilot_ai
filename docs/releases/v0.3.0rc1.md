# LabPilot AI 0.3.0rc1

此候选版将 Runmanager 的原生编译和提交、BLACS 执行、shot 归属、Lyse 分析及质量判定关联到同一持久化任务。托管 Runmanager 为每个请求创建独立批次目录，恢复原输出设置后将原生批次交给编译队列。BLACS 回调与 H5 元数据共同验证 shot 身份。Lyse 使用已审核的单发脚本在 H5 副本上分析，按每发结果执行数值、布尔或文本规则。

| 原生组件组合 | 测试 | 结果 |
| --- | --- | --- |
| Runmanager 3.3.0、BLACS 3.2.3、Labscript 3.4.2、Lyse 3.3.0 | 官方虚拟设备，两发 | 2 发编译、2 发入队、2 发执行、2 发分析，质量通过 |
| 同上 | 官方虚拟设备，两发，第二发质量超阈 | 两发证据保留，质量失败，任务为 `FAILED` |
| Runmanager 3.2.1、BLACS 3.2.1、Labscript 3.3.1、Lyse 3.2.3 | 官方虚拟设备，两发 | 2 发编译、2 发入队、2 发执行、2 发分析，质量通过 |

设备兼容包括 NI DAQmx 与 NovaTech DDS9M 的类型、单位、限值校验，以及 DDS、Andor 和 PrawnBlaster 已暴露的缓存或面板状态。控制机物理设备、本站科学指标和大规模批次性能待现场验收。兼容性声明覆盖表内组合。

安装指南见 [AUTOMATION.md](https://github.com/wxccl/labpilot_ai/blob/v0.3.0rc1/labpilot_ai/AUTOMATION.md)。
